# Примеры файлов для загрузки

Файлы, которыми проверяют загрузку на живой системе. Не выдумка «под демо»:
каждый воспроизводит случай, который встречается у хозяйств.

## `zagruzka-s-novymi-kolonkami.csv`

Двадцать коров с полным набором колонок шаблона **и пятью колонками,
которых книга не знает**:

| Колонка | Что это | Чем должна кончиться |
| --- | --- | --- |
| Упитанность (BCS) | балльная шкала 2,5…3,5 | кандидат в признаки |
| Ширина задней доли вымени | балл 3…9 | кандидат в признаки |
| Дата последней обрезки копыт | дата | скорее событие, чем признак |
| Рогатость | да / нет / комолая | признак наличия |
| Толщина сосков | сантиметры | кандидат в признаки |

**Что проверяется.** Двадцать животных заводятся, пять колонок не теряются:
отчёт загрузки называет их поимённо, а в кабинете Ассоциации, в разделе
«Новые колонки», появляются пять записей с примерами значений. Числа
из этих колонок в карточках не показываются — признак заводит Ассоциация,
а не файл.

**Разделитель — точка с запятой, дробная часть через запятую, кодировка
UTF-8 с BOM.** Так сохраняет Excel в русской раскладке, и так приходят
настоящие файлы хозяйств. Файл заодно проверяет распознавание разделителя
и кодировки.

Номера начинаются с `31240090` — если такие в книге уже есть, поменяйте
префикс, иначе загрузка честно откажет по совпадению номеров.
