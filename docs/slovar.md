# Словарь предметной области

Термины системы с привязкой к полям модели. Задача словаря — развести
понятия, которые звучат похоже и означают разное: в переписке и в задачах
их путают регулярно, а цена ошибки здесь высокая — от неверно прочитанного
отчёта до неверно выпущенного документа.

Поля даны так, как они называются в коде: `src/collections/Animals.ts`,
`src/lib/dictionaries.ts` и остальные коллекции. Там, где поля нет,
это сказано прямо.

---

## Что путают чаще всего

Шесть пар, ради которых написан этот документ. Подробности — в разделах ниже.

| Одно | Другое | Чем различаются |
| --- | --- | --- |
| **Уровень достоверности записи** (`trustLevel`, −1…3) | **Достоверность оценки** (`production.reliabilityLevel`, `health.reliabilityLevel`, 1…5) | Первое — кем проверены сами данные. Второе — насколько надёжен прогноз племенной ценности. Шкалы разные, источники разные, меняются независимо |
| **Достоверность оценки** (1…5) | **R, %** (`ipcDetails.r` и `r` у каждого признака, 0…100) | Первое — ступень готовности оценки для человека. Второе — статистическая величина: доля дисперсии истинной племенной ценности, объяснённая оценкой |
| **ИПЦ** (`ipc`) | **ПИ, продуктивный индекс** (`production.productionIndex`) | ИПЦ — свод по всем группам признаков: продуктивность, здоровье, воспроизводство, экстерьер. ПИ — свод только по продуктивным признакам, одна строка внутри блока продуктивности |
| **Прогноз** (`forecast` в любом блоке оценки) | **Фактическое значение** (`summary.*`, `lactations[]`) | Прогноз — оценка племенной ценности (EBV), наследуемая часть, которую животное передаёт потомству. Факт — то, что животное надоило само |
| **`publicVisible`** | **`publicDetails`** | Первое — запись видна в книге строкой списка. Второе — карточку можно открыть целиком. Второе без первого смысла не имеет, первое без второго — обычное состояние: запись в книге есть, подробности закрыты |
| **Инбридинг животного** (COI) | **Коэффициент родства** | COI — свойство одного животного. Коэффициент родства — свойство пары. Коэффициент родства пары вдвое больше, чем COI их будущего потомка |
| **Линия** (`line`) | **Семейство** (`family`) | Линия ведётся по отцам от родоначальника-быка, семейство — по матерям от родоначальницы. Поля разные, справочник за ними один (`lines`) |

## Оценка племенной ценности

Все блоки оценки устроены одинаково: у признака есть **прогноз**
(`forecast`) и **R, %** (`r`). У блоков продуктивности и здоровья сверх
того есть **достоверность оценки** (`reliabilityLevel`). Общий итог лежит
в `ipc` и разобран в `ipcDetails`.

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| ИПЦ, индекс племенной ценности | aggregate breeding index | `ipc` | Итоговое число оценки животного целиком, по всем группам признаков. Показывается в таблице поиска и в шапке карточки. Сейчас хранится как данность и системой не вычисляется |
| Прогноз ИПЦ | index EBV | `ipcDetails.forecast` | То же значение в разборе индекса. В карточке показывается оно, а `ipc` служит запасным |
| R, % | reliability | `ipcDetails.r`, а также `r` у каждого признака | Доля дисперсии истинной племенной ценности, объяснённая оценкой, от 0 до 100. Растёт с числом учтённых потомков и лактаций. Это не «достоверность оценки» и не уровень достоверности записи |
| Процентиль | percentile rank | `ipcDetails.percentile` | Место животного в сравниваемой группе: 88 означает, что 88 % группы имеют индекс ниже |
| Дата последней оценки | evaluation date | `evaluationDate` | Когда индекс пересчитывали. Требуется зоотехническим сертификатом |
| Достоверность оценки | reliability level | `production.reliabilityLevel`, `health.reliabilityLevel` | Шкала 1…5: 1 — оценка предварительная, 5 — подтверждена большим массивом данных. Стоит рядом с таблицами признаков, показывается подписью «Достоверность оценки: N из 5» |
| Продуктивные признаки | production traits | `production.milk`, `.fatPercent`, `.proteinPercent`, `.fatKg`, `.proteinKg` | Прогноз и R по каждому: удой, жир и белок в процентах и килограммах. Список — `PRODUCTION_TRAITS` |
| ПИ, продуктивный индекс | production index | `production.productionIndex.forecast`, `.r` | Свод по продуктивным признакам, одна строка внутри блока продуктивности. Не заменяет ИПЦ и не равен ему |
| Фертильность | fertility | `reproduction.fertility.forecast`, `.r` | Единственный признак блока воспроизводства, в баллах |
| Продуктивное долголетие | productive life | `health.productiveLongevity` | Насколько дольше средней ожидается продуктивная жизнь дочерей |
| Здоровье вымени | udder health | `health.udderHealth` | В баллах |
| Смертность приплода | calf mortality | `health.calfMortality` | В процентах |
| Лёгкость отёла (оценка) | calving ease | `health.calvingEase` | Прогноз по потомству, в баллах. Факт по конкретному отёлу лежит в `calvings.ease` |
| Экстерьер, линейная оценка | linear type traits | `exterior.<признак>` | 18 признаков по шкале −2…+2: рост, ширина груди, глубина туловища, постановка ног, прикрепление долей вымени и прочие. Список — `EXTERIOR_TRAITS` |
| Композиты экстерьера | type composites | `exterior.bodyComposite`, `.udderComposite`, `.legsComposite` | Сводные оценки тела, вымени и ног |
| Ранг по ИПЦ | sort rank | `ipcRank` | Служебное поле сортировки, см. «Служебные понятия» |

## Продуктивность и лактации

Это факт: то, что животное дало само. Прогнозы из блока оценки сюда
не попадают и наоборот.

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| Сводка показателей | summary | `summary.*` | Значения последней завершённой лактации, вынесенные в карточку и в таблицу поиска. Производные от лактаций, а не самостоятельный источник |
| Удой | milk yield | `summary.milkYield`, `lactations[].milkYield` | Удой за лактацию |
| Удой за 305 дней | 305-day yield | `lactations[].milk305` | Стандартная лактация ICAR. Сейчас принимается из импорта, а не вычисляется по контрольным дойкам |
| Жир и белок, % | fat, protein percentage | `summary.fatPercent`, `summary.proteinPercent`, `lactations[].fat305`, `.protein305` | Содержание в молоке |
| Жир и белок, кг | fat, protein kg | `summary.fatKg`, `summary.proteinKg`, `lactations[].fatKg`, `.proteinKg` | Валовой выход за лактацию |
| СБП | fat + protein yield | `summary.fatProteinSum` | Сумма жира и белка в килограммах. Считается автоматически при сохранении, вручную не заполняется |
| Дойные дни | days in milk | `lactations[].dd`, `calvings.milkingDays` | Продолжительность лактации в днях |
| Дата отёла в лактации | calving date | `lactations[].calvingDate` | С чего лактация началась |
| Запуск | dry-off | `lactations[].dryOffDate`, `calvings.dryOffDate` | Прекращение доения перед следующим отёлом |
| Сервис-бык | service sire | `lactations[].serviceBull` | Бык, которым корову осеменяли в эту лактацию. Хранится текстом, связью не является |
| Соматические клетки | somatic cell count | `lactations[].scc`, `milk-tests.somaticCells` | Факт замера, тыс./мл. Это не индекс SCS — индекса в модели нет |
| Контрольная дойка | test-day record | `milk-tests` | Отдельная запись на каждый замер: дата, суточный удой, жир, белок, соматические клетки, лаборатория, источник |
| Ранг по удою | sort rank | `summary.milkRank` | Служебное поле сортировки |

## Происхождение и инбридинг

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| Отец, мать | sire, dam | `father`, `mother` | Связи на карточки. Родителями могут быть только животные соответствующего пола, и оба не могут быть одним животным |
| Текстовая родословная | pedigree text | `pedigreeText.fatherId`, `.fatherName`, `.motherId`, `.motherName`, `.fatherFatherId`, `.motherFatherId` | Предки, которых нет карточками. Годятся для показа, но не для сертификата: там печатается номер каждого предка |
| Линия | sire line | `line` → `lines`, тип записи `line` | Мужская линия: ведётся по отцам от родоначальника-быка |
| Ветвь | branch | `lines`, тип записи `branch` | Подразделение линии |
| Семейство | dam family | `family` → `lines`, тип записи `family` | Маточное семейство: ведётся по матерям от родоначальницы. Поле отдельное, справочник тот же, что у линии |
| Колено | generation | `AncestorRow.generations` в `src/lib/ancestry.ts` | Номер ряда предков: родители — первое колено. Глубина разбора — `ANCESTRY_DEPTH`, девять колен |
| Коэффициент инбридинга, COI | inbreeding coefficient, F | вычисляется `analyzeAncestry` → `coi`; импортированное значение — `inbreeding` | Свойство **одного** животного: вероятность, что два аллеля одного локуса у него идентичны по происхождению. Формула Райта. Когда оба родителя связаны карточками, показывается расчёт; иначе — импортированное значение |
| Коэффициент родства | coefficient of relationship | поля нет | Свойство **пары** животных. Численно вдвое больше, чем COI их будущего потомка: у полных сибсов коэффициент родства 0,5, а F их потомка — 0,25 |
| Требует ручного подтверждения | manual approval | `inbreedingNeedsApproval` | Ставится автоматически при инбридинге выше 25 %. Порог 6,25 % — только предупреждение в интерфейсе |
| Доля крови предка | blood share | `AncestorRow.bloodShare` | Сумма (1/2)^колено по всем путям до предка, % |
| Кратность вхождений | occurrences | `AncestorRow.occurrences` | В сколько клеток родословной попадает предок |
| Вклад в инбридинг | contribution to COI | `AncestorRow.coiContribution` | Сколько процентов COI даёт этот предок. Сумма вкладов равна показанному коэффициенту |
| Общий предок | common ancestor | `AncestorRow.onBothSides` | Встречается и со стороны отца, и со стороны матери. Только такие предки дают вклад в инбридинг |
| Заполненность родословной | pedigree completeness | `AncestryReport.coverage` | Сколько различных предков известно в колене из 2^колено возможных |
| Ключевые предки | key ancestors | `AncestryReport.ancestors`, компонент `KeyAncestors` | Таблица предков, отсортированная по доле крови |

## Достоверность и проверка данных

Три величины со схожими названиями. Они не связаны между собой и меняются
независимо.

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| Уровень достоверности записи | data trust level | `trustLevel`, шкала −1…3; дата — `trustCheckedAt` | Кем проверены сами данные: −1 отклонено, 0 черновик, 1 проверено собственником, 2 подтверждено лабораторией, 3 верифицировано Ассоциацией. Свидетельство выпускается с уровня 3, в расчёт индексов запись попадает с уровня 2. Соответствует полю NTRUTH из технического задания |
| Достоверность оценки | reliability level | `production.reliabilityLevel`, `health.reliabilityLevel`, шкала 1…5 | Насколько надёжен прогноз племенной ценности: зависит от числа учтённых потомков, лактаций и полноты родословной |
| R, % | reliability | `ipcDetails.r` и `r` у каждого признака, 0…100 | Доля дисперсии истинной племенной ценности, объяснённая оценкой. Статистическая величина, а не ступень готовности |
| Пакет загрузки | data submission | `data-submissions` | Присланные данные как единица работы: тип, статус, файл, протокол проверки |
| Статус пакета | submission status | `data-submissions.status` | Загружено → на проверке → проверено → данные приняты (либо отклонено) |
| Протокол проверки | review protocol | `data-submissions.review.checkedBy`, `.checkedAt`, `.comment`, `.totalRows`, `.acceptedRows`, `.rejectedRows`, `.errorProtocol` | Кто проверил, когда, сколько строк принято и файл со строками, не прошедшими проверку |
| Согласие владельца | consent | `data-submissions.consent.agreed`, `.agreedAt`, `.publishedAt` | Публикация данных требует явного согласия владельца после проверки |
| История статусов | status history | `data-submissions.history[]` | Каждый переход с датой и именем. Пишется автоматически |
| Аудит записи | audit trail | `lastEditUser`, `lastEditTime` | Кто и когда менял карточку животного в последний раз |
| Источник данных | data source | `inseminations.source`, `milk-tests.source` | Ручной ввод, импорт файла, API, лаборатория, собственник |

## Видимость и доступ

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| Показывать в публичном списке | listed publicly | `publicVisible` | Запись присутствует в книге строкой: номер, кличка, владелец, основные показатели |
| Открыть полную карточку | full card public | `publicDetails` | Карточку можно открыть целиком, в том числе анонимно. Снимается решением владельца, а не фактом входа в систему |
| Замок | lock | вычисляется `isAnimalLocked` в `src/lib/visibility.ts` | Карточка закрыта: владелец не открыл подробности, и смотрит не он и не Ассоциация |
| Своё животное | own animal | вычисляется `isOwnAnimal` | Владелец записи совпадает с организацией посетителя |
| Посетитель | viewer | `Viewer` в `src/lib/visibility.ts` | Организация, признак администратора, признак входа в систему |
| Запрос доступа | access request | `access-requests` | Обращение к владельцу закрытой карточки. Решение принимает владелец, Ассоциация видит переписку |
| Цель запроса | purpose | `access-requests.purpose` | Покупка, приобретение семени, подбор пар, проверка происхождения, научная работа, другое |
| Решение по запросу | decision | `access-requests.status`, `.decidedAt`, `.decidedBy`, `.response` | Ожидает решения, доступ открыт, отказано. Дата и автор проставляются автоматически при смене состояния |
| Роль | role | `users.role` | Фермер/заводчик, сервисная организация, физическое лицо, администратор. Роль `admin` в форме регистрации отсутствует |
| Заявка подтверждена | confirmed | `users.confirmed` | Ассоциация подтвердила регистрацию. Меняется только администратором |
| Выставлено на продажу | for sale | `forSale` | Признак витрины продаж, заполняется хозяйством |
| Уведомления просмотрены | notifications seen | `users.notifySeenAt` | Отметка времени, по которой считается непрочитанное |

## Служебные понятия системы

| Термин | English | Поле | Что означает |
| --- | --- | --- | --- |
| Пакет загрузки | data submission | `data-submissions`, номер — `number` | Единица работы Ассоциации с данными хозяйства. Один пакет проходит несколько статусов и столько же раз появляется в ленте событий |
| Архив | archive | `archived`, `archiveReason`; условие `NOT_ARCHIVED` в `src/lib/animal-query.ts` | Запись остаётся в системе и открывается по прямой ссылке, но исключена из списков и счётчиков. Данные не удаляются никогда |
| Служебная запись предка | synthetic ancestor | животное с `identNumber` вида `ANC…` и `archived: true` | Карточка, заведённая ради построения родословной вглубь. В стаде такое животное никогда не стояло, поэтому в книге ему не место. Создаёт их `src/scripts/deep-pedigree.ts` |
| Ранг сортировки | sort rank | `ipcRank`, `summary.milkRank` | Копия значения для сортировки по убыванию. Пустое значение превращается в −1 000 000, иначе PostgreSQL поставил бы записи без оценки в начало списка. Заполняется хуком коллекции |
| Быстрый отбор | preset filter | `PRESETS` в `src/lib/animal-query.ts` | Готовый набор условий отбора под частый вопрос. Это условия, а не порядок показа |
| Порядок показа | sort order | `SORT_OPTIONS` в том же файле | Четыре варианта сортировки. Порядок по убыванию возможен только через служебные ранги |
| Лента уведомлений | notifications feed | собирается `loadNotifications` в `src/lib/notifications.ts` | Отдельной таблицы уведомлений нет: лента строится из запросов доступа и пакетов загрузки в момент показа |
| НСИ | reference data | 15 коллекций из `DICTIONARY_COLLECTIONS` | Справочники с единым составом полей: `code`, `name`, `sortOrder`, `isActive`, `description`. Живут в базе и правятся через админ-интерфейс |
| Признак «Используется» | active flag | `isActive` у справочника | Снятая отметка убирает значение из выпадающих списков, не трогая записи, где оно уже проставлено |
| Событие | event | `events` | Общая лента фактов по животному: отёл, осеменение, запуск, контрольная дойка, оценка экстерьера, ветобработка, перемещение, выбытие |

## Сокращения

| Сокращение | Расшифровка | Что означает |
| --- | --- | --- |
| **ИПЦ** | индекс племенной ценности | Итоговая оценка животного по всем группам признаков, поле `ipc` |
| **СБП** | сумма белка и жира | Валовой выход жира и белка за лактацию, кг; поле `summary.fatProteinSum` |
| **ПИ** | продуктивный индекс | Свод по продуктивным признакам, `production.productionIndex` |
| **ГПК** | государственная племенная книга | Марка и номер записи в ней: `altIds.gpkMark`, `altIds.gpkNumber` |
| **НСИ** | нормативно-справочная информация | Справочники системы, коллекции из `DICTIONARY_COLLECTIONS` |
| **EBV** | estimated breeding value | Оценка племенной ценности по родословной и фенотипу. В модели это поля `forecast` |
| **gEBV** | genomic estimated breeding value | Оценка племенной ценности с учётом генотипа. В модели пока нет |
| **PTA** | predicted transmitting ability | Половина EBV — то, что животное передаёт потомку. Североамериканская форма записи той же величины |
| **COI** | coefficient of inbreeding | Коэффициент инбридинга животного, `AncestryReport.coi` |
| **ROH** | runs of homozygosity | Протяжённые участки гомозиготности; по ним считают геномный инбридинг F_ROH |
| **SNP** | single nucleotide polymorphism | Однонуклеотидный полиморфизм — маркер, на котором построены генотипирование и проверка происхождения |
| **SCS** | somatic cell score | Логарифмический индекс соматических клеток. В модели есть только факт замера (`lactations[].scc`, `milk-tests.somaticCells`), индекса нет |
| **PL** | productive life | Продуктивное долголетие; ближайшее поле — `health.productiveLongevity` |
| **DPR** | daughter pregnancy rate | Показатель воспроизводства по дочерям. Отдельного поля нет, ближайшее — `reproduction.fertility` |
| **NM$** | Net Merit dollars | Экономический индекс США. В модели не хранится, упоминается как ориентир при проектировании пользовательского индекса |
| **TPI** | Total Performance Index | Индекс Holstein Association USA. В модели не хранится |
| **ICAR** | International Committee for Animal Recording | Отраслевой орган, чьи Guidelines определяют правила учёта продуктивности; см. `docs/standarty.md` |
| **ФГИАС ПР** | федеральная государственная информационно-аналитическая система племенных ресурсов | Государственная система учёта. Под неё заготовлен `uuid`; спецификаций обмена в открытом доступе нет |
| **ВетИС** | Федеральная государственная информационная система в области ветеринарии | Система Россельхознадзора; компонент «Хорриот» отвечает за маркирование и учёт животных |
