# Изображения сайта

Положите сюда файлы с этими именами — код подхватит их автоматически,
править ничего не нужно. Подходят `.jpg`, `.png`, `.webp`, `.avif`.

| Файл | Где используется | Рекомендуемый размер |
| --- | --- | --- |
| `hero-plemkniga.jpg` | главная, блок справа от «Племенная книга» | 1200 × 800 |
| `contacts.jpg` | страница регистрации, блок «Если возникнут вопросы» | 1000 × 1000 |
| `login.jpg` | страница входа | 900 × 500 |

Логотип шапки и подвала — отдельный файл: `public/logo.svg`
(можно `.png` или `.webp`). Высота в вёрстке 42 px, ширина по пропорциям.

Пока файла нет, на его месте рисуется векторная заглушка.
